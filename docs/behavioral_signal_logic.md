# Confidence & Stress Indicators – Zecpath AI

## Objective

To evaluate candidate confidence and behavioral signals during AI interviews.

## Key Signals

| Signal        | Description                |
| ------------- | -------------------------- |
| Hesitation    | Filler words               |
| Repetition    | Word redundancy            |
| Uncertainty   | Confidence-related phrases |
| Pause         | Speaking speed estimation  |
| Sentiment     | Emotional tone             |
| Stress        | Nervous indicators         |
| Contradiction | Logical inconsistency      |

## Confidence Formula

Confidence Score =

(Repeat × 0.25) +
(Hesitation × 0.25) +
(Uncertainty × 0.25) +
(Pause × 0.25)

## Behavioral Score Formula

Behavioral Score =

(Confidence × 0.5) +
(Sentiment × 0.2) +
(Stress × 0.3)

## Advantages

* Captures confidence indicators
* Evaluates communication quality
* Supports AI screening decisions
* Produces explainable scores

## Limitations

* Rule-based detection
* No voice-tone analysis
* Limited emotional understanding

## Future Improvements

* Emotion recognition
* Voice analysis
* ML-based behavioral scoring
* Multilingual support
