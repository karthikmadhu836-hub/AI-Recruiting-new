# ATS Testing Report

## Objective

To evaluate system performance across different job roles and candidate profiles.

## Test Categories

* Technical roles
* Non-technical roles
* Fresher resumes
* Senior profiles

## Methodology

* Selected sample job descriptions
* Compared AI predictions with manual evaluation
* Used similarity threshold of 0.6

## Observations

* High accuracy for technical roles
* Moderate accuracy for non-technical roles
* Better performance on experienced candidates

## Limitations

* Keyword dependency
* Limited contextual understanding
