# Structured Summary Template

```json
{
  "candidate_id": "C101",
  "overall_score": 78.5,
  "decision": "Strong Hire",
  "summary": {
    "strengths": [],
    "weaknesses": [],
    "risks": [],
    "inconsistencies": [],
    "cultural_fit": "Good"
  },
  "natural_language_summary": ""
}
```

## Fields

| Field                    | Description                       |
| ------------------------ | --------------------------------- |
| candidate_id             | Candidate identifier              |
| overall_score            | Final aggregated interview score  |
| decision                 | Strong Hire / Consider / Reject   |
| strengths                | Positive candidate attributes     |
| weaknesses               | Areas requiring improvement       |
| risks                    | Potential concerns                |
| inconsistencies          | Contradictions detected           |
| cultural_fit             | Team and organizational alignment |
| natural_language_summary | Recruiter-friendly explanation    |
