# Zecpath AI Hiring System

## Overview

Zecpath AI is an intelligent recruitment platform that automates the hiring lifecycle using Artificial Intelligence.

---

# Features

- Resume Parsing
- ATS Scoring
- AI Screening
- HR Interview Evaluation
- Technical Interview Evaluation
- Machine Test Evaluation
- Behavioral Analysis
- Integrity Detection
- Decision Engine
- Recruiter Reports

# Installation

## Clone Repository

```bash
git clone https://github.com/your-repository/zecpath-ai.git
```

---

## Create Virtual Environment

```bash
python -m venv venv
```

---

## Activate Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# Run Application

```bash
python main.py
```

---

# Run Demo

```bash
python demo/full_pipeline_simulation.py
```

---

# Run Tests

```bash
pytest
```
