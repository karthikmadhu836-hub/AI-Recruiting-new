# Communication Scoring Formula

## Formula

Communication Score =

(Fluency × 0.20)

* (Grammar × 0.20)

* (Vocabulary × 0.20)

* (Clarity × 0.20)

* (Structure × 0.20)

− Filler Penalty

---

## Parameter Definitions

| Parameter  | Description                   |
| ---------- | ----------------------------- |
| Fluency    | Sentence continuity and flow  |
| Grammar    | Basic grammatical correctness |
| Vocabulary | Diversity of words used       |
| Clarity    | Length and understandability  |
| Structure  | Logical explanation           |
| Penalty    | Filler word deduction         |

---

## Score Levels

| Score    | Level     |
| -------- | --------- |
| 85–100   | Excellent |
| 70–84    | Good      |
| 50–69    | Average   |
| Below 50 | Poor      |
