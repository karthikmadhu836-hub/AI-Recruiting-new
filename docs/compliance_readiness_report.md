# AI Compliance Readiness Report – Zecpath

## Objective

To ensure the HR AI system follows responsible data handling, privacy protection, and compliance best practices.

---

# Data Retention Policy

Candidate information is retained for a maximum period of 90 days.

After 90 days:

- Data is anonymized, or
- Permanently deleted

Recruiters may request deletion at any time.

---

# Compliance Standards Alignment

| Standard | Status |
|------------|---------|
| GDPR | Partial Alignment |
| Data Minimization | Implemented |
| Consent Management | Implemented |
| Right to Erasure | Supported |

---

# Security Measures

- Encrypted data storage
- Secure API communication
- Role-based access control
- Audit logging enabled
- Controlled access permissions

---

# Risk Assessment

| Risk | Mitigation |
|---------|------------|
| Bias Risk | Fairness Review Checks |
| Data Misuse | Access Control |
| Model Errors | Human Review Process |
| Unauthorized Access | Encryption & Authentication |

---

# Explainability Requirements

AI decisions provide:

- Final score
- Score breakdown
- Hiring recommendation
- Strengths and weaknesses
- Reasoning behind decisions

### Example

```json
{
  "final_score": 78,
  "explanation": {
    "ats": "Strong skill match",
    "screening": "Good clarity and relevance",
    "hr": "High confidence and communication"
  }
}
```
