# Interview Flow Design Document

## Phase 1: Introduction

* Candidate introduction
* Academic background
* Professional summary

## Phase 2: Core HR Questions

* Strengths
* Weaknesses
* Teamwork
* Communication

## Phase 3: Role-Based Evaluation

### Technical Roles

* Problem solving
* Technical challenges
* Tools and technologies

### Non-Technical Roles

* Client handling
* Business problem solving
* Communication

## Phase 4: Closing

* Salary expectations
* Notice period
* Joining availability

## Flow

START

↓

Introduction

↓

Core HR Questions

↓

Role-Based Questions

↓

Closing Questions

↓

Generate Report

↓

END

## Follow-Up Trigger Rules

Trigger follow-up when:

* Answer contains less than 5 words
* Candidate says "Not sure"
* Candidate provides vague response

Example:

Question:
"What are your strengths?"

Candidate:
"Teamwork"

Follow-up:
"Could you please elaborate on your strengths?"
